# Enterprise-GenAI-Knowledge-Platform

## Project Overview

This project extends Retrieval-Augmented Generation (RAG) into a production-style Enterprise AI system with:

- Multi-source data ingestion
- Multimodal query support
- Multilingual retrieval
- Evaluation agent

## Tasks Implemented

### Task 1
Multi-source enterprise data integration

### Task 2
Multimodal AI support

### Task 3
Multilingual retrieval support

### Task 4
Evaluation agent implementation

## Technologies Used

- Python
- FAISS
- Transformers
- Tesseract OCR
- BLIP
- LaBSE
- LangChain
